# BTC/USDT Probabilistic Trading System

A full-stack reference implementation of a probability-based BTC/USDT trading
signal system: live dashboard, model monitoring, automated retraining,
backtesting, an admin panel for risk controls, and a Dockerized deployment.

> **This system never claims certainty.** Every prediction is expressed as a
> probability (never exactly 0% or 100%), every signal ships with a
> confidence score and a SHAP-based explanation of *why* it was generated,
> and nothing here is financial advice.

## 2. Pages

| Page | Route | Contents |
|---|---|---|
| Dashboard | `/` | Live BTC/USDT chart, BUY/SELL/HOLD signal, prob-up, prob-down, confidence, open positions, PnL |
| Model Monitoring | `/monitoring` | Daily/weekly accuracy, win rate, Sharpe ratio, profit factor, max drawdown, calibration curve |

## 3. Quick start (Docker)

```bash
git clone <this-repo>
cd btc-trading-system
cp .env.example .env        # edit values as needed (defaults work for local dev)
docker compose up --build
```

- Frontend: http://localhost:3000
- Backend API + docs: http://localhost:8000/docs
- Postgres: localhost:5432 (user/db from `.env`)
- Redis: localhost:6379

On first boot the backend:
1. Backfills ~1000 recent 1-minute BTC/USDT candles from Binance's public REST API.
2. Opens a live WebSocket stream for real-time price ticks.
3. Starts the scheduler (daily ingestion, weekly retrain, per-minute signal generation, nightly monitoring snapshot).

**No model exists yet on a fresh install.** Go to the Retraining page and
click **"Retrain Now"** once enough candles have backfilled (a minute or
two), or wait for the next scheduled run. Until a model is trained and
promoted to "champion", the Dashboard will show no signal and Backtesting
will be unavailable.

## 4. Local development (without Docker)

Backend:
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# Point DATABASE_URL / REDIS_URL at local or dockerized Postgres/Redis
uvicorn app.main:app --reload
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Database (if not using Docker's `postgres` service):
```bash
psql -U <user> -d <db> -f db/init.sql
```

## 6. Safety & responsible-use notes

- Trading is **disabled by default**. It must be explicitly turned on in the
  Admin Panel, and the system only paper-trades (simulated fills) unless you
  wire up real exchange order execution yourself — this reference
  implementation intentionally does not include live order placement.
- All probability outputs are clamped away from 0/1 (see
  `app/ml/signal_engine.py`) — the system is architecturally incapable of
  emitting a "certain" prediction.
- Every signal includes a SHAP-derived explanation of the top contributing
  features, surfaced in the Dashboard and stored alongside the signal in
  Postgres for auditability.
- This is a reference/educational implementation, not investment advice, and
  markets carry real risk of loss. Backtested performance does not guarantee
  future results.
